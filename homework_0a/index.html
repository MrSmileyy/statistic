Theoretical Overview: Weierstrass Curves and Scalar Multiplication

1. Scalar Multiplication and Meaning of k

Given an elliptic curve defined over a finite field 𝔽p and a generator G ∈ E(𝔽p), scalar multiplication represents the repeated addition of G with itself:

Q = k ⋅ G = G + G + ... + G   (k times)

The integer k defines the number of iterations along the group law (iG = (i-1)G + G for i = 2, ..., k). In asymmetric cryptography (ECC), k acts as the private key, while the resulting point Q constitutes the public key.

2. Group Law and Slope Calculation s

Given two points P = (xP, yP) and Q = (xQ, yQ) on the curve, the line connecting them has slope s computed analytically:

  • Point doubling (P = Q):
    The tangent line at P is computed. Differentiating the Weierstrass equation y2 = x3 + ax + b:
    s ≡ (3xP2 + a) ⋅ (2yP)-1 mod p
  • Addition of distinct points (P ≠ Q):
    The secant line passing through both points is computed:
    s ≡ (yQ - yP) ⋅ (xQ - xP)-1 mod p

In modular arithmetic, the inverse of the denominator is computed using the Extended Euclidean Algorithm.

3. Finding the Third Point and Reflection

A line intersects the cubic curve at three points. Substituting the line y = s(x - xP) + yP into the curve equation, Vieta's formulas for the roots of the cubic polynomial yield:

x3 ≡ s2 - xP - xQ mod p

The y coordinate of the third intersection point on the line is:

yint ≡ s(xP - x3) - yP mod p

By the axiomatic definition of an abelian group, three collinear points sum to the identity element: P + Q + (-R) = Ο. Therefore, the result R = P + Q is the opposite of the third intersection point (reflection across the x-axis):

y3 ≡ -yint mod p ==> R = (x3, y3)

4. Point at Infinity (Ο)

When xP = xQ and yP ≡ -yQ mod p, the line is vertical (s = ∞). It does not meet a third affine point in the plane, but intersects the curve at the ideal point at infinity Ο, the identity element of the group: P + (-P) = Ο.

How to choose the Base G?

The base point G = (x, y) cannot be chosen arbitrarily. It must be a point that lies on the curve.

To check if a point lies on the curve, substitute x and y into the equation:

y2 ≡ x3 + ax + b (mod p)

Example: for y2 = x3 + 7 (mod 17), the point (1, 5) is valid because:

  • y2 = 52 = 25 ≡ 8 (mod 17)
  • x3 + 7 = 13 + 7 = 1 + 7 = 8 (mod 17)

If you enter an invalid point, the application will display an error.
